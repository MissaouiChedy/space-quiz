# Orbit — Space Exploration Quiz

Orbit is a self-contained, responsive space exploration quiz. Answer ten multiple-choice questions, get immediate feedback and a score, then play again. It supports keyboard navigation, reduced motion, and light and dark system themes.

## Run locally

No installation, build step, or server is required. Open `index.html` in a modern browser.

## Deployment

The GitHub Actions workflow in `.github/workflows/deploy-pages.yml` publishes `index.html` to GitHub Pages whenever changes are pushed to `main`. Pull requests run the static-site packaging job; deployment happens after changes are merged.
